Investigation tools

Validate a finding

Offline checks never contact a provider. AWS verification sends the supplied credentials to AWS STS when you press the live test button. Validation results are not saved.

Ethereum mainnet balance

Checks native ETH for a public address at a recorded block. Your RPC provider receives the address. Tokens, NFTs and other networks are not checked.

Azure Storage live key test

Explicitly sends a signed, read-only service-properties request to the Azure Blob endpoint for this account. A failure can be inconclusive.

GitHub token live test

Sends the supplied token to GitHub’s authenticated-user endpoint. A failure can be inconclusive for installation tokens and permissions.

AWS STS live credential test

Enter a matching pair. Temporary ASIA credentials also need a session token. A rejected or inconclusive result is not proof of safety.

Azure live validation supports Storage account Shared Keys only; other Azure credentials are not tested. The ETH balance check covers native ETH on Ethereum mainnet only; it does not establish key ownership.

Response guidance

Confirm suspected private material using a trusted, private workflow. If exposed, stop using the affected wallet, move assets to a newly generated wallet using a trusted device, investigate access logs, and remove the exposure and cached copies. Assess public addresses in their business and privacy context.
